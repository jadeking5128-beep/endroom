# ENDROOM roadmap

## Phase 1 — Foundation
- [x] Replace the previous game with ENDROOM.
- [x] Establish responsive terminal-first interface and project documentation.

## Phase 2 — Linux engine and access
- [x] Full-screen terminal interface with no guest mode.
- [x] Server-side username/password verification using scrypt hashes.
- [x] Encrypted, secure session cookies.
- [x] Isolated E2B sandbox provisioning and reconnection.
- [x] Restricted command execution and sandbox timeout.
- [ ] Configure Vercel environment variables and validate a live sandbox.

## Phase 3 — Workspace
- [ ] File browser and safe editor.
- [ ] Multiple terminal tabs and session management.
- [ ] Additional reviewed development tools.

## Phase 4 — Security and launch
- [ ] Shared rate limiting and security monitoring.
- [ ] Data retention and deletion controls.
- [ ] Independent security review and production hardening.
