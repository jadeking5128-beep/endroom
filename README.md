# ENDROOM

A 2D top-down pixel-art escape room adventure. Explore a locked room, inspect objects, collect clues, solve the keypad puzzle, and find the exit.

## Play

The game is a static HTML5 Canvas project. Open `index.html` locally or deploy the repository to Vercel.

- Move: WASD or arrow keys
- Interact: E or Space
- Mobile: on-screen directional pad and tap-to-inspect
- Inventory: select collected items in the pocket grid

## Deploy on Vercel

Import `jadeking5128-beep/endroom` as a new Vercel project. No build command or framework preset is required; serve the repository root as a static site.
